# Diferencias entre la versión borrador (2026A) y la revisada (2026D)

← [Índice](./README.md) | ← [Degradación de comunicaciones](./07-degradacion-comunicaciones.md)

| Aspecto | 2026A (borrador) | 2026D (revisión) |
|---|---|---|
| Mobility autónoma (por traverse) | 10 pts | 15 pts |
| Destreza multiplicador TA | x4 | x10 |
| Destreza multiplicador AA | x8 | x20 |
| Operational tasks | 10 pts cada una | E-Stops 8, Valves 10, Keys 10 |
| Sensor Crate — "Visual/Color Acuity" | Sí, 1 pt | No aparece |
| Sensor Crate — 2-Way Audio | 1 pt | 2 pts |
| Multiplicador de mapeo autónomo | x4 (bonus aislado solo al mapeo) | x5 (integrado a la fórmula general: TeleOp x1, Comms degradada x2, Autónomo x5) |
| Entrega de mapas | Hasta 3 mapas aceptados en rondas posteriores | No se menciona ese detalle explícitamente en el extracto disponible |
| Normalización general | MOB + DEX (máx. 200% por carril) | MOB + DEX + EXP (máx. 300% por carril) |

La diferencia más relevante para el software: **2026D integra
mapeo/exploración directamente en el puntaje normalizado por carril**,
mientras 2026A lo trataba como bonus aislado — bajo 2026D, el mapa
generado importa para el puntaje general, no solo para un
reconocimiento aparte.

Se trata **2026D como la versión de referencia** por decisión del
equipo, por ser la revisión más reciente (tiene changelog fechado
6/3/2026 documentando cambios sobre una base anterior). TMR publicó
2026A_Draft en su página; si cambia el reglamento del siguiente año,
se corrigen estos documentos.
